# 🔋 Smart Energy Consumption Forecasting

This project is a machine learning-powered web application that predicts real-time household energy consumption based on past data. It promotes energy efficiency using a regression-based time series model.

## 🚀 Features

- 📈 Predicts future energy usage based on user input
- 💡 Regression model trained on real-world energy dataset
- 🌐 Interactive web interface (HTML, CSS, JS)
- 🧠 Backend with Flask & Python
- 📁 Clean and modular project structure

## 🧠 Technologies Used

- Python, Flask
- scikit-learn, pandas, joblib
- HTML5, CSS3, JavaScript (Fetch API)
- Jupyter/Colab for model training

## Dataset Used
Link:"https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption"

## 🔧 How to Run
1. Clone this repo  
2. Install requirements: `pip install -r requirements.txt`  
3. Run Flask app: `python app.py`  
4. Open browser at: `http://127.0.0.1:5000`
